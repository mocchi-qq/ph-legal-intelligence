## Per-source questions

For each source in `sources.authorization.json`:

1. **Description** — issuing organisation and material types.
2. **Intended acquisition** — none proposed at Gate 1; a future reviewed connector.
3. **Intended storage** — original artifact in private object storage, hash recorded.
4. **Transformation** — text extraction, structural normalisation, passage segmentation, indexing.
5. **Full-text display** — would users see the original text? Proposed: link to the official source; display only short passages with attribution.
6. **Passage display** — proposed: yes, with source URL, retrieval date and attribution.
7. **Redistribution** — proposed: no bulk redistribution; no rehosting of third-party databases.
8. **Attribution** — organisation, document title, official identifier, source URL.
9. **Restrictions** — unknown pending terms capture.
10. **Open questions** — see checklist.
11. **Evidence gathered** — only `robots.txt` checks (see matrix). No terms archived yet.
12. **Counsel determination** — _to be completed by counsel; intentionally blank._

## Counsel review checklist

- [ ] Is a government publication protected by copyright, and does the IP Code permit the intended reproduction?
- [ ] Does the site's terms of use prohibit automated access, bulk download, or commercial reuse?
- [ ] Does displaying short passages with attribution fall within fair use / permissible quotation?
- [ ] Does storing a private archival copy for verification create a redistribution risk?
- [ ] Are there data-privacy issues in published decisions (personal data of parties, minors, sensitive cases)?
- [ ] Does the repository's takedown/removal process satisfy any source requirement?
- [ ] Is a written licence or permission letter required before any bulk acquisition?
- [ ] What attribution format does each source require?
- [ ] Are there restrictions on derivative indexes or embeddings derived from the text?
- [ ] What is the recommended posture for `lawphil` as a secondary source?
